miyuki-ui is a library of <Count of="components" /> React components: backgrounds and effects, everyday controls, pickers, overlays, charts and AI blocks.

It is not a package you depend on. Each component is a file. The shadcn CLI copies it into your project, next to your own components, and from then on it is yours to change.

## How it looks

Everything follows one idea: snow and water. Surfaces are cool and quiet. Anything selected, switched on or in progress fills with water blue. Text and the main action are deep ink. Every component is designed for the light and the dark theme.

Colours, radii, shadows and fonts come from CSS variables, so a component picks up your theme. See [Theming](/docs/theming).

## What you need

- React 19, in Next.js or another React 19 app.
- Tailwind CSS v4.
- TypeScript, with the `@/` import alias.
