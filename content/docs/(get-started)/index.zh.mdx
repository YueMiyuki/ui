miyuki-ui 是一个包含 <Count of="components" /> 个 React 组件的库：背景与特效、常用控件、选择器、浮层、图表和 AI 区块。

它不是一个需要你依赖的软件包。每个组件就是一个文件。shadcn CLI 会把它复制到你的项目中，与你自己的组件放在一起，此后由你随意修改。

## 外观 [#how-it-looks]

一切都遵循同一个理念：雪与水。各种表面清冷而安静。凡是选中、开启或进行中的元素，都会以水蓝色填充。文字和主要操作使用深墨色。每个组件都为浅色和深色主题而设计。

颜色、圆角、阴影和字体都来自主题变量，因此组件会沿用你的主题。参见[主题](/zh/docs/theming)。

## 所需环境 [#what-you-need]

- React 19，可以是 Next.js 或其他 React 19 应用。
- Tailwind CSS v4。
- TypeScript，并配置 `@/` 导入别名。
